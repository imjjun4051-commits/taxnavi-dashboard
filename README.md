# 텍스내비 (TaxNavi)

> 내년 실적을 미리 보고, 세금은 미리 설계하세요 — 광주·전남 중소기업 재무 내비게이터

재무팀이 없는 중소기업 대표가 최근 3개년 재무데이터를 넣으면 **내년 실적과 세금 예측**을 보여주고, **적용 가능한 세액공제**와 **우리 지역 정부지원사업**을 한 화면에서 보여 주는 웹서비스입니다. 서버 없이 `index.html` 파일 하나로 동작합니다.

## 바로 실행 (3가지 중 하나)
1. **더블클릭** — `index.html`을 브라우저(크롬·엣지·사파리)로 엽니다. 샘플 데이터로 바로 체험 가능(기업마당 API는 CORS로 막혀 샘플 대체).
2. **로컬 서버** — `vercel dev` → http://localhost:3000 (기업마당 API 실호출 가능, 프록시 `/api/bizinfo` 경유).
3. **배포** — `vercel --prod` → 배포 주소로 접속(팀·현장 시연용, GitHub 연동 없이 CLI 직접 업로드).

오른쪽 위(모바일은 아래) **샘플 데이터 불러오기** → **분석 시작 →** 을 눌러 흐름을 확인합니다. 우리 회사 숫자로 바꿔 입력하면 즉시 자동 저장됩니다.

## 업종 평균(DART 실데이터) 갱신
`docs/industry-avg.json`의 업종 평균은 DART(전자공시시스템)의 **코스닥·코넥스 상장기업** 실제 사업보고서로 계산합니다(코스피 대기업 제외). 인증키는 Vercel 환경변수 `DART_API_KEY`(로컬은 `.env.local`)에 등록되어 있습니다.
```
node tools/update-industry-avg.js   # DART에서 실제 데이터를 가져와 docs/industry-avg.json 갱신
node tools/inline-data.js           # index.html 인라인 데이터 동기화
```
- 업종별 표본기업 수가 다릅니다(제조업 7곳·정보통신업 8곳 vs 도소매업 3곳·서비스업 2곳) — 코스닥·코넥스 안에서 각 업종에 맞는 상장사가 그만큼만 확인됐기 때문입니다.
- 음식·숙박업은 코스닥·코넥스 상장사를 찾지 못해 샘플값을 유지합니다.
- 감가상각비는 DART 표준 재무제표 API에 계정과목으로 없어("주석"에만 있음) 전 업종 "데이터 없음"으로 표시됩니다.
- 자주 바뀌는 값이 아니므로 몇 달에 한 번, 또는 배포 전에 한 번씩 실행하면 충분합니다(주기적 캐싱).

## 데이터를 고치려면
1. `docs/*.json` 또는 `sample-data.json`을 수정합니다 (세무 수치는 `기준연도`·`확인일`·`출처`도 함께).
2. 프로젝트 폴더에서 `node tools/inline-data.js` 를 실행합니다 → `index.html` 안의 인라인 데이터가 갱신됩니다.
   (더블클릭으로 연 HTML은 보안정책 때문에 `docs/*.json`을 직접 읽을 수 없어 데이터를 인라인합니다.)

## 기업마당 Open API
인증키는 **서버(Vercel 환경변수 `BIZINFO_API_KEY`)에 미리 등록**되어 있어 화면에서 따로 입력할 필요가 없습니다.
`vercel dev`(로컬) 또는 배포 주소로 열면 지원사업 화면 진입 시 서버 프록시 `api/bizinfo.js`를 거쳐 **자동으로** 실시간 공고를 불러오고, 화면 위 소스 칩("기업마당 실시간" / "샘플 데이터")으로 결과를 확인할 수 있습니다. 실패하면 자동으로 샘플 데이터로 대체됩니다.
더블클릭(file://)으로 열면 서버가 없어 항상 샘플 데이터입니다.
인증키를 새로 발급하려면: 기업마당 로그인 → 활용정보 → 정책정보 개방 → 지원사업정보 API 신청 후 Vercel 프로젝트 환경변수에 `BIZINFO_API_KEY`로 등록하고 재배포하세요. (Claude Code로 신청을 진행하는 프롬프트는 `PROMPT_GUIDE.md` 5단계 — 단, 발급받은 키 값은 채팅에 붙여넣지 말고 Vercel 대시보드나 별도 터미널에서 직접 등록하세요)

## ERP CSV 자동 인식 (GPT API)
입력 화면 사이드바(분석 시작 아래) "ERP CSV 불러오기" 버튼을 누르고 회사 ERP가 내보낸 CSV 파일을 선택하면, 계정과목 순서·이름이 회사마다 달라도 GPT가 매출액·영업이익·인건비·유형자산·감가상각비·이자비용을 찾아 재무데이터 표를 자동으로 채웁니다(단위 원/천원/백만원/억원 자동 환산). 데모용 가상 데이터를 채우려면 재무데이터 표 위 "자동 입력(샘플)" 세그먼트를 사용하세요.
`vercel dev`(로컬) 또는 배포 주소에서만 동작합니다(서버 프록시 `api/parse-financials.js` 경유, 더블클릭은 서버가 없어 사용할 수 없음). GPT API 인증키는 Vercel 프로젝트 환경변수에 `OPENAI_API_KEY`로 등록해야 합니다(**아직 미등록 — 등록 전에는 "GPT API 키가 서버에 등록되지 않았습니다" 오류가 표시됩니다**). CSV 내용은 처리를 위해 OpenAI API로 전송되며 이 서버는 CSV·결과 모두 저장하지 않습니다.

## 계산 기준 (2026-09-03 확인, 상세는 `docs/tax-rules.json`)
- 법인세: 법인세법 제55조 — 과세표준 2억 이하 10% / 200억 이하 20% / 3,000억 이하 22% / 초과 25% (2026.1.1. 이후 개시 사업연도) + 지방소득세 10%
- 부가세: (과세 매출 − 과세 매입) × 10%
- 통합고용세액공제(조특법 §29의8) · 통합투자세액공제(§24) · 근로소득증대세제(§29의4): 2026년 개정 기준
- 시나리오 가정: 인건비·감가상각비 고정, 그 외 비용은 매출과 같은 비율로 변동

> ⚠️ 이 서비스의 세금·공제 금액은 입력값을 바탕으로 한 **단순 추정치**입니다. 실제 세액은 과세표준 조정, 최저한세, 공제 한도, 사후관리 요건 등에 따라 달라지므로 신고 전 반드시 세무사 등 전문가의 확인을 받으세요.
