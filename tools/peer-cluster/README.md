# 동종 상장기업 비교군 분석 (peer-cluster)

우리 회사(비상장 중소기업)와 **같은 업종의 코스닥·코넥스 상장기업**을 모아 3개 군으로 나누고,
우리 회사가 어느 군에 속하는지, 그 군이 과거에 실제로 매출이 늘었는지 리포트로 만들어 줍니다.

텍스내비 본체(`index.html`)와는 **완전히 독립**된 CLI 도구입니다. 본체 파일을 건드리지 않습니다.

## 설치

```bash
pip install -r tools/peer-cluster/requirements.txt
```

## 실행

```bash
# 1) 키 없이 연습 (tests/fixtures의 가짜 회사 20곳으로 전체 과정을 그대로 실행)
python tools/peer-cluster/run.py --target tools/peer-cluster/sample_target.json --dry-run

# 2) 실제 데이터 (DART 키 필요)
cp tools/peer-cluster/.env.example tools/peer-cluster/.env   # 편집기로 키를 넣으세요
python tools/peer-cluster/run.py --target tools/peer-cluster/sample_target.json
```

| 옵션 | 설명 |
|---|---|
| `--target` | 기준 기업 JSON 경로 (필수) |
| `--year` | 기준연도 (기본: target 파일의 기준연도) |
| `--min-peers` | 최소 비교군 수 (기본 15) |
| `--model` | GPT 모델 (기본 `gpt-4o-mini`) |
| `--no-cache` | 캐시를 무시하고 새로 호출 |
| `--dry-run` | API 호출 없이 가짜 데이터로 전체 실행 |

## 결과물

- `reports/peer-cluster_{회사명}_{YYYYMMDD}.md` — 표 중심 리포트 (+ `_cagr.png` 상자그림)
- `tools/peer-cluster/` 아래 CSV: `peers.csv`, `revenue_history.csv`, `clusters.csv`,
  `growth_by_cluster.csv`, `disclosures.csv`

## 입력 파일 형식 (sample_target.json)

금액 단위는 **백만원**입니다(도구가 내부에서 원 단위로 환산해 상장사와 비교합니다).
값이 없는 항목은 `null`로 두면 되고, 그 경우 보조 특성 없이 필수 4개 특성만 씁니다.

```json
{
  "회사명": "샘플정밀(주)",
  "업종코드": "2929",
  "기준연도": 2025,
  "매출액":   {"2023": 4200, "2024": 4650, "2025": 5100},
  "영업이익": {"2023": 260,  "2024": 310,  "2025": 380},
  "당기순이익": {"2025": null}, "자산총계": {"2025": null},
  "부채총계":   {"2025": null}, "자본총계": {"2025": null}
}
```

> `sample_target.json`의 업종코드 `2929`(기타 특수 목적용 기계 제조업)는 실제 확인값이 아니라 **가정**입니다.

## 모듈 구성 (각 파일이 하는 일)

| 파일 | 하는 일 |
|---|---|
| `dart_client.py` | OpenDART 호출 공통부. 재시도 3회·호출 간 0.2초·일일 20,000건 카운터·파일 캐시(고유번호 30일 / 개황 30일 / 재무 1일 / 공시 1시간) |
| `peers.py` | 상장사 중 코스닥·코넥스만 남기고, 업종코드 앞자리가 같은 회사를 고름. 15곳 미만이면 자릿수를 4→3→2로 줄여 확장 |
| `financials.py` | 최근 5개 사업연도 주요계정 수집(100개씩 묶어 호출). 연결(CFS) 우선, 없으면 개별(OFS) |
| `features.py` | 특성 계산: log매출액·매출성장률·영업이익률·3년 CAGR(+보조 3개). 윈저라이징 1~99% → 표준화 |
| `cluster.py` | K-means(k=3, random_state=42) 학습, 실루엣 점수, 기준 기업을 가장 가까운 중심에 배정 |
| `gpt_label.py` | 나뉜 군에 GPT가 A/B/C 라벨·이름·기준 서술을 붙임. 실패하면 군번호 순 A/B/C 대체 |
| `growth.py` | 군별 5년·3년 CAGR·최근 1년 성장률과 증가 기업 비율 → 성장/정체/감소 판정 |
| `disclosures.py` | 소속 군 회사의 최근 12개월 공시 수집, 유상증자·최대주주 변경 등 '주의' 표시 |
| `report.py` | 위 결과를 마크다운 리포트로 조립(+ 군별 3년 CAGR 상자그림) |

## K-means와 GPT의 역할 (비전공자용 설명)

**K-means**는 회사들을 숫자 특성(규모·성장률·수익률)만 보고 서로 비슷한 것끼리 3덩어리로 자동으로 묶는
계산 방법입니다. 사람이 "이 회사는 이 그룹"이라고 정하지 않고, 각 덩어리의 중심점을 찾아 가장 가까운
중심에 회사를 붙이는 과정을 반복합니다. **우리 회사가 어느 군에 속하는지는 이 계산(수학)이 정합니다** —
우리 회사의 숫자를 상장사들과 같은 자로 재서 가장 가까운 중심을 고를 뿐입니다.

**GPT**는 이미 나뉜 군에 **이름과 설명만** 붙입니다. "0번 군"처럼 뜻 없는 번호 대신 "안정 중견 제조군"
같은 이름과 "매출 2,000억 이상·성장률 한 자릿수" 같은 기준 문장을 사람이 읽기 쉽게 써 주는 역할입니다.
**GPT는 어느 회사가 어느 군에 들어갈지 정하지 않고, 숫자를 바꾸지도 않습니다.** GPT를 못 쓰는 상황이면
A/B/C만 자동으로 붙고 나머지 분석은 그대로 진행됩니다.

## 한계

- DART의 `induty_code`는 소분류(3자리)까지만 있는 회사가 많아 세분류(4자리) 매칭이 항상 되지는 않습니다.
- 연결/개별 재무제표가 섞여 있어 규모 비교에 오차가 있을 수 있습니다.
- 코넥스는 재무 항목 누락이 잦아 일부 회사가 분석에서 빠집니다.
- 상장기업 비교군이라 비상장 중소기업 평균과는 성격이 다릅니다.
- **투자 권유가 아니며 참고용입니다.** 출처: 금융감독원 전자공시시스템(DART).
