# 텍스내비 대시보드 리디자인 + 기업마당 API 프록시 — 설계서

- 작성일: 2026-09-03
- 상태: 사용자 승인 (브레인스토밍 5문항 → 설계 5섹션 승인 → 4섹션 Vercel 구조로 수정 승인)
- 관련 문서: STEERING.md(규칙) · SPECS.md(Task) · DEVELOPMENT_LOG.md(기록)

## 1. 목표와 범위

**목표**
1. 현재 "상단 탭 4개" 화면을 **전문가용 대시보드**(좌측 다크 사이드바 + 라이트 본문, 밀도 높은 표·차트)로 전면 리디자인한다.
2. 기업마당 지원사업정보 Open API를 **서버 프록시**로 호출해 브라우저 CORS 문제를 없애고, 로컬(`vercel dev`)과 운영(`vercel --prod`)에서 같은 코드로 동작시킨다.
3. 리디자인 후에도 기존 기능(입력·자동 저장·계산·차트·절세·지원사업·CSV·인쇄·초기화)이 전부 동작함을 자동 검증(Playwright)으로 확인한다.

**범위 밖 (이번에 하지 않음)**
- 계산 로직 변경(`계산_법인세`·`계산_시나리오`·`계산_절세전략`·`계산_업종비교`) — 그대로 재사용
- 업종 평균·샘플 공고의 실데이터 교체(Task 15·16), 세무사 검토(Task 17), 다크 모드·JSON 백업(Task 18)
- 별도 `server.js`(Vercel CLI 없는 PC용) — 필요해지면 `api/bizinfo.js` 핸들러를 require하는 25줄 파일로 추가
- GitHub 커밋·푸시 (사용자 지시로 금지, Vercel은 CLI 직접 업로드)

## 3. 앱 셸(레이아웃)

### 3.1 반응형 구조
| 폭 | 사이드바 | 내비 | 액션(CSV·인쇄·초기화) |
|---|---|---|---|
| ≥1024px (데스크톱) | 좌측 고정 240px, 다크 | 사이드바 메뉴 5개(아이콘+라벨) | 사이드바 하단 |
| 768~1023px (태블릿) | 좌측 고정 72px, 아이콘만 | 아이콘 + `title` 툴팁 | 사이드바 하단 아이콘 |
| <768px (모바일) | 숨김 | **하단 고정 탭바 5개**(아이콘+짧은 라벨) | 본문 맨 아래 `.actions` 줄 |

- 본문은 `max-width 1400px`, 좌우 패딩 24px(모바일 16px). 가로 스크롤 금지(표는 `.table-wrap` 안에서만).
- 인쇄 시 사이드바·툴바·하단 탭바 숨김, 5개 화면 모두 출력(기존 인쇄 CSS 확장).

### 3.2 사이드바 구성 (위→아래)
1. 브랜드: 기존 나침반 심볼 + "텍스내비" + 한 줄 소개(작게, 태블릿 이하 숨김)

3. 구분선
4. 액션 3개: CSV 내보내기 · 인쇄/PDF · 데이터 초기화 (기존 버튼 id 유지: `btn-export-csv`·`btn-print`·`btn-reset`)
5. 하단 캡션: "세제 기준연도 2026 · 확인일 2026-09-03" + 자동 저장 상태 칩(`#save-status`)

### 3.3 툴바(본문 상단, sticky)

- 우: 회사명 칩 · 예측연도 칩 · (개요·분석 화면) 시나리오 세그먼트 `보수 | 기본 | 낙관`(`#quarter-switch` 역할 승계 → id `scenario-switch`, 선택값은 `상태.선택시나리오`에 저장)

## 5. 디자인 토큰 (STEERING 4항 준수)

- 기존 오렌지/쿨그레이 hex **추가 없음**. 사이드바용 시맨틱 토큰 3개만 기존 값에 매핑:
  - `--sidebar-bg: var(--gray-900)` · `--sidebar-fg: var(--gray-300)` · `--sidebar-active: var(--primary-500)`
  - 사이드바 활성 항목 배경 `rgba(255,96,0,.14)`(primary-500의 투명도 — 새 색상이 아님), 호버 `rgba(255,255,255,.06)`
- 밀도: 카드 패딩 20→16px, 표 글자 13px, 표 안 입력 36px, KPI 값 26px(`--fs-h3`), 툴바 높이 56px
- 라운드(입력 8 / 버튼 12 / 카드 16 / 칩 999)·서체 Pretendard·크기 스케일·간격 4px 배수 **유지**
- 차트 색: 예측 오렌지 / 실적·평균 회색 유지. 개요의 시나리오 막대는 선택 시나리오만 오렌지, 나머지 `--primary-200`
- 접근성: 내비 `role=navigation` + `aria-current="page"`, 하단 탭바 버튼 44px 이상, 사이드바 글자(gray-300 on gray-900) 대비 ≥ 7:1, 포커스 링 유지

## 6. API 프록시와 배포

### 6.1 `api/bizinfo.js` (Vercel Node 서버리스 함수, 의존성 0)
```
GET /api/bizinfo?crtfcKey=…&dataType=json&searchCnt=100[&hashtags=광주]
 → https://www.bizinfo.go.kr/uss/rss/bizinfoApi.do?(동일 쿼리)
 ← 응답 본문 그대로(JSON), Content-Type 유지, 상태코드 전달
```
- `module.exports = async (req, res) => {…}` 형태. Node 18+ 내장 `fetch` + `AbortController`(8초 타임아웃, Vercel Hobby 함수 제한 10초 안에서 종료)
- 허용 쿼리 키만 전달(`crtfcKey`·`dataType`·`searchCnt`·`hashtags`·`pageUnit`·`pageIndex`) — 임의 URL 프록시가 되지 않도록 대상 호스트 고정
- **인증키는 저장·기록하지 않음**: 오류 로그에는 키를 `****`로 마스킹한 URL만 남김
- 실패(타임아웃·상위 오류) 시 `502 { "error": "기업마당 응답 실패", "detail": "…" }` → 브라우저는 기존대로 샘플 대체 + 원인 표시
- `vercel.json` 최소 설정(`{"functions": {"api/bizinfo.js": {"maxDuration": 10}}}`) — 정적 `index.html`은 루트에서 자동 서빙

### 6.2 `index.html` 변경 (`기업마당_불러오기`)
- `location.protocol`이 `http:`/`https:`이면 `/api/bizinfo?…` 호출, `file:`이면 기존 직접 호출 유지
- 성공/실패 처리·캐시·샘플 대체 로직은 기존 그대로. 실패 문구에서 "2일차 서버(프록시)…" 안내를 "vercel dev 또는 배포 주소에서 열면 프록시로 호출됩니다"로 갱신

### 6.3 실행·배포 명령
- 로컬: `vercel dev` → `http://localhost:3000` (첫 실행 시 프로젝트 연결 질문 → 새 프로젝트 "taxnavi-dashboard"로 생성, 사용자가 답함)
- 배포: `vercel --prod` (GitHub 연동 없음). 배포 URL은 DEVELOPMENT_LOG.md에 기록
- 더블클릭(file://)은 계속 동작 — API만 샘플로 대체

### 6.4 인증키 발급 절차 (사용자 수행)
1. bizinfo.go.kr 로그인(회원가입 필요 시 사업자 정보) → 상단 "활용정보" → "정책정보 개방" → "지원사업정보 API" → 인증키 신청
2. 발급된 키를 지원사업 화면 "기업마당 연동" 패널에 입력 → "기업마당에서 불러오기"
3. 결과(성공 건수 또는 오류 문구)를 DEVELOPMENT_LOG.md에 기록 — **키 자체는 어디에도 기록하지 않음**

## 7. 검증

- `tools/test-e2e.py` 갱신
  - `URL` 환경변수(`TEST_URL`)로 `file://` 기본, `http://localhost:3000`, 배포 주소 모두 검사 가능
  - 선택자 갱신: `#tab-*` → `#nav-*`(사이드바) / 모바일은 `#mnav-*`(하단 탭바), `#quarter-switch` → `#scenario-switch`, `.scenario` → `#scenario-table th`, 개요 화면 검사 추가(KPI 4개·일정 3건·임박 공고), `/api/bizinfo` 프록시 검사(서버 URL일 때만: 키 없음 → 400, 잘못된 키 → 502 또는 기업마당 오류 JSON)

- 콘솔 JS 오류 0, 새로고침 유지, 초기화 후 LocalStorage 비움, 인쇄 CSS는 `page.emulate_media(media='print')` 스크린샷으로 확인
